## 접속 정보·자동 배포·main 전환

Runtime Secrets는 INITIAL_TEACHER_PASSWORD, INITIAL_ADMIN_PASSWORD 두 개입니다. 운영용 비밀번호는 로컬 시험값과 다른 무작위 값으로 설정했고 문서·Git·응답·로그에 출력하지 않았습니다. 사용자의 로컬 private-data/Cloudflare_접속정보.local.md에만 접속 정보를 보관합니다. 관리자 화면에서 변경할 수 있으며 기존 DB 비밀번호는 이후 배포의 초기 Secret으로 덮어쓰지 않습니다.

GitHub 자동 빌드 연동은 미설정입니다. 기존 Wrangler OAuth로 Builds API를 조회하면 403 Authentication error가 발생했습니다. 현재 서비스는 검증 브랜치 소스를 CLI로 직접 배포한 상태입니다. 자동 연동 시 별도 권한이 있는 사용자 API token 또는 대시보드 연결로 production branch를 codex/cloudflare-workers-migration으로 지정하고 Preview를 끕니다. 비밀값을 채팅이나 Git에 붙여 넣지 않습니다.

사용자가 확인 후 main 전환을 결정하면 코드 검토·병합과 배포 브랜치 변경을 진행합니다. Worker·D1·Secrets·저장 계획서는 그대로 사용하며 DB 초기 입력이나 전체 복원을 다시 실행하지 않습니다. 이번 작업에서는 main 병합, 이전 Pages 삭제, 요금제 변경을 하지 않았습니다.

원격 CPU 정량 측정·무료 요금제 보장·실제 프린터 출력·원본 Excel 실물 재가져오기·제공되지 않은 과거 운영 계획 이관은 이 검증 결과에 포함하지 않습니다.
